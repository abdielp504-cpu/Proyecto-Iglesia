# Proyecto-Iglesia

Sistema de Gestión Eclesiástica construido con React, Vite y Tailwind CSS.

## Fase 1

Incluye autenticación, control de acceso basado en roles, gestión de usuarios y configuración institucional. Los datos se inicializan desde `src/data/seedData.js` y se mantienen en `localStorage`.

## Instalación

```bash
npm install
npm run dev
```
